# カツオ島

[カツオ一本釣り](https://github.com/teitasan/katsuo-ippon) から分岐した、別ゲーム。

一本釣りは3分のスコアアタック。こちらはそれを捨てて、
**漁 → 帰港 → 換金 → 投資 → 再出港** を繰り返す継続型にした。

- 制限時間は無い。かわりに**燃料**が航海の限界になる。燃料は走った距離で減るので、
  残量はそのまま航続距離。止まって釣っているあいだは減らない
- 魚はスコアではなく**積荷**。港に持ち帰ると自動で水揚げ・換金・給油される。船倉に上限は無い
- 強化は run 中に起きない。港で買う。考えることは全部港に隔離する
- 港から遠いほど群れが大きくなる。上限つきの傾斜ではなく **一定距離ごとに倍** なので、
  いちばん稼げる漁場が「満タン÷2」に比例して無段階に沖へ滑っていく。
  素の小型船では沖に出るほど損をして、船とタンクを伸ばすほど漁場が外へ移る
- 燃料が切れても終わらない。強制帰港して、その漁だけ半値になる
- 船体レベルアップは廃止。造船所で小型 → 中型 → 大型に乗り換える。装備は引き継ぐ

さわる数字は `ippon.html` 内の
`PORT` / `SEA` / `FUEL` / `YEN` / `SHIPS` / `PRICE` / `TANK_STEP` に集めてある。
