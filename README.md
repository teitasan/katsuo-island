# カツオ島

[カツオ一本釣り](https://github.com/teitasan/katsuo-ippon) から分岐した、別ゲーム。

シンプルな「カツオ一本釣り」をテーマにした経営シミュレーション。
**漁 → 帰港 → 換金 → 島へ投資 → 再出港** を繰り返す。
自分の一本釣りが資金を稼ぐ直接のプレイで、島が育つほど一本釣りの規模そのものが大きくなる。

- 海上の操作は船を動かすだけ。航海中の強化は無く、強化は全部島への投資に集める
- 船倉の上限は無い。遠くの海ほど魚群が大きい。ときどき鳥山（大群）が湧く
- 海には難所がある。急潮・時化は固定、嵐・台風は流れてくる。船が小さいと押し戻され、大きい船なら抜けられる。中は魚が濃い
- 乗り切れない住民は、前の段階の船でNPCとして漁に出て、帰港したぶんが所持金に入る
- 燃料は走ると減り、止まっていても少し減る。使い切っても罰は無く、暗転して港へ戻る。
  メニューからいつでも帰港できる
- 島の施設は Lv0〜10（造船所は0〜4）。条件を満たすと次の施設・Lvが解放され、
  お金を払って建てると能力が恒久的に上がる。解放にお金はかからない。
  条件はすべて人口（何を建てても増える）なので、どの施設から上げても次の船や上のLvに届く
  - 造船所：木造の小舟 → 漁船 → 大型漁船 → タイタニック → 戦艦大和（乗員上限 8/18/32/50/70）
  - 整備場：船の速さ　漁具工房：竿の本数　水産加工場：売値　燃料タンク：航続距離
  - 魚探と集魚は Lv1 固定
- 施設を上げるたびに島の人口が増え、その人数が漁師として船に乗る。家も増えていく

さわる数字は `island.html` 内の `FAC` / `FAC_EFF` / `REQ` / `POP` / `SHIPS` / `FUEL` / `SEA` / `TORI` / `HAUL` に集めてある。
